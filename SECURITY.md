# Security

This code holds real funds on mainnet. If you find a way to steal, freeze or mint without backing, please report it privately through [GitHub's security advisories](https://github.com/blume-bridge/blume-bridge/security/advisories/new), never in a public issue.

Include what you found, how to reproduce it, and what it would cost the bridge. You will get an answer.

Things that are already known and documented are not vulnerabilities: one operator runs every node and holds the upgrade key, the lock account's master keys are still on, and Evernode hosts can read the keys of the instances they run. See "The trust model today" in the [README](README.md).
